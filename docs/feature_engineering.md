# 特徵工程設計說明

`build_features()`（`stockta/features/pipeline.py`）是訓練與推論唯一共用進入點，
輸出 17 個特徵；順序由 `FEATURE_COLUMNS` 固定並寫入 artifact metadata，
API 啟動時比對，不一致拒絕載入。

## 特徵清單與設計理由

| 特徵 | 定義 | 設計理由 |
|---|---|---|
| `ret_1d` / `ret_5d` | 1 / 5 日報酬率 | 最直接的動能訊號；報酬率天然尺度無關 |
| `close_ma5/10/20/60` | 收盤價 ÷ N 日均線 − 1 | **相對值化**：不同股價尺度（20 元 vs 1000 元）下特徵分佈一致；乖離率語義（價格偏離均線程度） |
| `rsi14` | Wilder RSI，縮放 0–1 | 超買超賣；縮放到 0–1 與其他特徵尺度一致 |
| `macd` / `macd_signal` / `macd_hist` | (EMA12−EMA26)÷收盤價、其 9 日 EMA、兩者差 | **除以收盤價轉尺度無關**（原始 MACD 與股價成正比）；三者組合涵蓋趨勢方向與轉折 |
| `bb_pctb` | 布林通道 %B（20,2） | 價格在通道內的相對位置；σ=0 平盤取中性值 0.5 |
| `bb_width` | 通道寬 ÷ MA20 | 波動收斂/擴張（squeeze）訊號 |
| `kd_k` / `kd_d` | 隨機指標（9,3,3 台股慣例），縮放 0–1 | 短線超買超賣與金叉死叉資訊 |
| `vol_ratio` | 成交量 ÷ 20 日均量 − 1 | 量能相對水準（放量/縮量） |
| `vol_chg` | 成交量日變化率 | 量能突變訊號 |
| `hl_range` | (高−低) ÷ 收盤 | 日內波動幅度（已尺度無關） |

## 三條硬性設計約束

1. **因果性（無前視）**：所有指標只用當日與更早的資料（rolling/EMA 皆左對齊），
   `test_no_lookahead.py` 以「截斷未來資料重算，特徵逐值不變」驗證。
2. **相對值化**：價格類特徵一律轉為比值/報酬率，成交量除以均量——
   跨 49 檔股價尺度差兩個數量級的股票共用同一模型的前提。
3. **暖機期一致**：EMA 類指標（RSI/MACD/KD）受序列起點影響，推論端依
   `INDICATOR_WARMUP_DAYS = 120` 提供暖機資料，EMA(26) 殘差降到 1e-4 量級後
   推論特徵才與訓練期一致；`test_feature_parity.py` 依此容忍度把關。

## 標準化

`StandardScaler` 只 fit 訓練期（≤2022-12-31）的列——驗證/測試期分佈對 scaler
不可見（防洩漏）；scaler 與模型一起存入 artifact，推論端直接重用。

## 實作備註

- 技術指標以 pandas 自行實作：PyPI 版 pandas-ta（0.3.14b0）與 numpy≥2 不相容
  （`numpy.NaN` import 錯誤），公式簡單自實作反而可控（PLAN.md Phase 0 決策）。
- 除權息：`auto_adjust=True` 固定寫入 config 與 metadata——台股除權息頻繁，
  訓練/推論調整方式不一致會讓除息日前後特徵與標籤全失真。
